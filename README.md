# Tietoliikenteen sovellusprojekti 2025

Projektin tarkoituksena on siirtää kiihtyvyysanturidataa Nordicin mikrokontrollerilta Linux-palvelimella sijaitsevaan tietokantaan käyttäen välikappaleena Raspberry Pi -alustaa, johon data siirtyy BLE-teknologian avulla. Raspberry Piltä data välitetään edelleen TCP-yhteyden avulla palvelimelle, jossa se tallennetaan MySQL-tietokantaan.
